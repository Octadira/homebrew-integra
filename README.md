# Homebrew Tap for Integra

Official Homebrew Tap for [Integra](https://github.com/Octadira/integra) — Native macOS SSHFS & AI Agent Workspace Manager.

## Installation

```bash
# Add tap and install Integra
brew install --cask octadira/integra/integra
```

Or add the tap first:

```bash
brew tap octadira/integra
brew install --cask integra
```

## Updates

```bash
brew upgrade --cask integra
```
